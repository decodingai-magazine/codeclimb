# 11: Tracer night: one mock round on the Inngest dev server

**What to build:** The first night that works end to end. The CLI validates the config, sends `codeclimb/night.start` with the stable event id, and follows `results.jsonl`. The worker connects to the dev server as app `codeclimb-worker` and serves `run-night`, which runs init, then one round by invoking the `run-experiment` and `run-evaluator` children, decides with the keep rule, records the row, scores the checkpoint on test, sweeps its sandboxes and writes `done.json`. Review, notes, noise, metering, the smoke test and stop handling come in later tickets; this ticket wires step bodies that already exist into durable functions.

**Spec sections** (`docs/codeclimb-spec-inngest.md`): "Goal and done signal", "Components", "CLI", "Mock mode", "Experiment lifecycle", "Ids", "Init", "Round loop", "Interfaces", "Events", "Durable runtime on Inngest", "Cleanup", "Files a night writes", "Result row", "Deployment and environment"

**Blocked by:** 04 (Decision functions: weighted score, keep rule, noise margin, soft stops); 05 (Result rows: schema, deduplicated append, validate-results); 09 (Coder experiment: from the prompt to one commit); 10 (Evaluator: an unmetered evaluation with latency metrics)
