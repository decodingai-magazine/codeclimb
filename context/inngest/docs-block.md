## Inngest docs and tools

- Inngest docs for coding agents: https://www.inngest.com/llms.txt (an index of every docs page as markdown), and the full text in one file: https://www.inngest.com/llms-full.txt
- TypeScript SDK reference: https://www.inngest.com/docs/reference/typescript
- MCP server `inngest-dev`: the Inngest dev server serves it at http://127.0.0.1:8288/mcp (the dev server is already running). Its tools work against your local app (functions, events, runs) and search the Inngest docs.
