## LangChain docs and tools

- LangChain docs for coding agents: https://docs.langchain.com/llms.txt (an index of every docs page as markdown), and the TypeScript pages alone: https://docs.langchain.com/_llms/agent-development-lifecycle/build/type-script.txt
- JavaScript API reference: https://reference.langchain.com/javascript
- MCP server `langchain-docs`: searches and reads the LangChain docs.
- MCP server `langsmith`: your LangSmith workspace (traces, runs, datasets, prompts), with the key in `/app/.env`.
